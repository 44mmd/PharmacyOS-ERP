فحص الجهاز · Checking this computer

    سيطلب Windows الإذن مرة واحدة. يحتاج التثبيت إلى الإنترنت هذه المرة فقط (تنزيل حوالي 1.5 غيغابايت) ويستغرق 20–40 دقيقة. قد يُطلب إعادة تشغيل الجهاز مرة واحدة ويكمل الإعداد تلقائيًا بعدها.

    Windows will ask for permission once. Installing needs the internet this one time (about 1.5 GB) and takes 20–40 minutes. Windows may need one restart; setup then continues by itself.

      خادم الصيدلية لا يستجيب · The pharmacy server is not answering
      
		
      لم يُفقد أي بيع محفوظ. جرّب بالترتيب: No saved sale is lost. Try, in this order:
      
		
        
			
      1. اضغط «تشغيل الخادم» وانتظر دقيقتين. Press "Start the server" and wait two minutes.
        2. 
			
      2. تأكد أن جهاز الخادم يعمل ومتصل بشبكة الصيدلية. Check that the server PC is on and connected to the pharmacy network.
        3. 
			
      3. أعد تشغيل هذا الجهاز ثم افتح PharmacyOS. Restart this computer, then open PharmacyOS.
        4. 
			
      4. إذا استمرت المشكلة، تواصل مع الدعم وأرسل ملف السجل من مجلد PharmacyOS\Logs. If it continues, contact support with the log from the PharmacyOS\Logs folder.
        5. 
		
      
		
      
			
			
			
		
      
		
      
	
      

	
      
		
      تحديث خادم الصيدلية · Pharmacy server update
      
		
      هذه النسخة من PharmacyOS تحمل تحديثًا لخادم الصيدلية:  ← . تُؤخذ نسخة احتياطية أولًا؛ وإذا فشل أي شيء يعود الخادم تلقائيًا إلى النسخة السابقة ببياناته. يستغرق 5–10 دقائق، ويتوقف البيع خلالها.
      
		
      This version brings a pharmacy server update. A backup is taken first; if anything fails the server returns to the previous version with its data. It takes 5–10 minutes; selling pauses meanwhile.

      النسخ الاحتياطية · Backups
      
		
      يأخذ PharmacyOS نسخة احتياطية تلقائيًا كل ساعة ونسخة كاملة يوميًا، في المجلد C:\ProgramData\PharmacyOS\Backups. انسخ هذا المجلد إلى قرص خارجي بانتظام.
      
		
      PharmacyOS backs up every hour (database) and every day (database and files) into C:\ProgramData\PharmacyOS\Backups. Copy that folder to an external drive regularly.
